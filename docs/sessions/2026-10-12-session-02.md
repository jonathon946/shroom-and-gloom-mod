# Session 02 — 2026-10-12 — tooling to reproduce situations, then the backlog

Scope, from the maintainer's request: build what is needed to reproduce backlog items without a playthrough, then work the backlog in the agreed order before taking on new findings.

## What we did

- **Tooling.** `tools/Snapshot.ps1` saves and loads named copies of the save (`far-run-tunnel4` is the maintainer's far run). The dev bridge gained `addcard`, `energy`, `heal`, `killall`, `list` and `focus TEXT`; `Test-Run.ps1` gained `dev:<command>` and `until:<regex>` tokens. With these the grimoire was reproduced on demand: load the snapshot, add a Reveal card, cast it.
- **Backlog 2, the grimoire and other card-change screens.** The message is spoken first, then the cards; focus lines held back during the message are spoken when the hold ends instead of being lost; the changed card is read ("The card is now: ... Enter takes it. Left is No thanks."). The changed card is not under the screen's own root, so it is found as the card nearest the Take button that is not in the hand.
- **Backlog 3, statuses on the player.** The Player buffer lists them, each with the game's explanation. The player model has no list of statuses, so every status asset is asked whether the player has it.
- **Backlog 5, the class screen.** A locked character says "locked". The settings heading rule no longer applies outside settings. A card is called "Your hand" only when the game is in hand mode.
- **Backlog 6, the old marks.** The screenshots for playthrough b marks 1, 4, 12 and 13 were read. Marks 4, 12 and 13 show no text the mod misses. Mark 1 (first landing in a new game) shows a hand holding a note with a wordless picture: a stick pushed forward. The mod now says, once, "A hand holds up a note with a picture: push forward. Hold W to walk." Mark 3 (fast double Enter) is still open.
- **Backlog 7, first parts.** A fifth buffer, Help, with seventeen lines covering the keys, the rows and the buffers; the title greeting says where it is. `mod/README.txt` for players (what is needed, install, keys, removal, credits). `tools/Package-Mod.ps1` builds `dist/ShroomAccess-<version>/` and a zip holding only the mod, its data file, Prism and Prism's licences, and the README.
- **Wording.** Enemy intents are spoken as "Will attack for 5", "Will block 3", "Will use Psychic Scream 2" instead of the internal names. A thing with a use the game shows as unknown says "Looks breakable. Also takes something unknown." instead of running the words together.

## Risk analysis

- **Nothing in this session has been heard.** Two sessions of work now rest on log reading. The next step should be a playthrough, not more features.
- **The package has not been installed from scratch.** The README's steps are written from what was done on this machine, where the loader was installed by script, not by the installer the README points to.
- **Strings are still literals in the code.** The project rule asks for a table; the Help buffer added seventeen more. This grows the cost of the later move.
- **The save was reset to fresh and restored from the snapshot** during the first-landing test. The far run is back; a copy of the save as it stood before the reset is in `backups/`.
